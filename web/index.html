Features

Built for explicit control.

Mountlet does not hide provider behavior behind a black box. It uses rclone, keeps credentials in rclone's normal config, and makes cached/offline file state visible.

  • Integrated file browser without mounting.
  • Optional native folder mounting.
  • Managed cache and offline files.
  • Encrypted config bundle import/export.
  • Google Drive, Dropbox, OneDrive, Box, pCloud, Proton Drive, and S3-compatible paths.

Primary beta platform. Plasma X11 has the fullest tray behavior; GNOME and Wayland have desktop limits.

FAQ

Short answers before you install.

Does Mountlet replace rclone?

No. Mountlet is a desktop interface around rclone. The bundled build includes an app-local rclone for convenience.

Do I need FUSE, WinFsp, or macFUSE?

Only for native folder mounting. The integrated file browser works through rclone without filesystem mounting.

Is this open source?

The source is available for non-commercial use. Commercial use or redistribution requires separate permission.
