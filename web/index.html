Features

Most daily cloud work, without provider hopping.

Keep many accounts close at hand, open files through your normal apps, and decide which files stay available when the network is not.

Accounts

Add and switch between many cloud accounts from different providers. Keep work, personal, archive, and project storage visible in one compact place.

Files

Browse cloud folders directly inside Mountlet, open files with the apps already configured on the computer, and drag files into cloud folders without first mounting the remote.

Offline

Keep selected files or folders available locally. Mountlet separates ordinary temporary cache from protected offline copies, so cleanup does not remove files you chose to keep.

Sync

When cached or offline files change locally, Mountlet can upload the edit if the cloud copy has not changed. If both sides changed, it asks which version to keep.

Mount

Mount cloud accounts as ordinary folders for Finder, Explorer, Dolphin, and other file managers when the platform filesystem driver is installed.

Move

Use encrypted config bundles to move cloud account settings between your own devices. Mountlet can also watch a chosen cloud path for newer config bundles.

How it works

A friendly desktop layer over a proven cloud engine.

Mountlet uses rclone under the hood. rclone is the connection layer that knows how to talk to many cloud providers. Mountlet adds the desktop interface, file browser, cache handling, setup helpers, and optional native mounting controls.

Bundled build

Includes an app-local rclone. This is the easiest choice for most people and does not replace a system rclone.

Lean build

Uses rclone already installed on the computer. This is lighter for technical users, admins, and managed machines.

Native mounting

Install FUSE, WinFsp, or macFUSE to make cloud accounts appear as ordinary folders in your system file manager.

FAQ

Short answers before you install.

Can Mountlet replace provider desktop apps?

For many daily file tasks, yes. Provider apps may still be better for provider-specific sharing, collaboration, or backup features.

Do I need FUSE, WinFsp, or macFUSE?

Mountlet's integrated file browser works without them. Add the platform filesystem driver when you want Mountlet to mount cloud accounts as ordinary folders too.

What is rclone?

It is the cloud connection engine Mountlet uses behind the scenes. The bundled build includes it for convenience.

Is this open source?

The source is available for non-commercial use. Commercial use or redistribution requires separate permission.
