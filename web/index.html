Features

          
Most daily cloud work, without provider hopping.

          

            Keep many accounts close at hand, open files through your normal apps, and decide
            which files stay available when the network is not.
          

        

        

          

            Accounts
            
Add and switch between many cloud accounts from different providers. Keep work, personal, archive, and project storage visible in one compact place.

          

          

            Files
            
Browse cloud folders directly inside Mountlet, open files with the apps already configured on the computer, and drag files into cloud folders without first mounting the remote.

          

          

            Offline
            
Keep selected files or folders available locally. Mountlet separates ordinary temporary cache from protected offline copies, so cleanup does not remove files you chose to keep.

          

          

            Sync
            
When cached or offline files change locally, Mountlet can upload the edit if the cloud copy has not changed. If both sides changed, it asks which version to keep.

          

          

            Mount
            
Mount cloud accounts as ordinary folders for Finder, Explorer, Dolphin, and other file managers when the platform filesystem driver is installed.

          

          

            Move
            
Use encrypted config bundles to move cloud account settings between your own devices. Mountlet can also watch a chosen cloud path for newer config bundles.

          

        

      


      

        

          
How it works

          
A friendly desktop layer over a proven cloud engine.

          

            Mountlet uses rclone under the hood. rclone is the access layer that knows how
            to talk to many cloud providers. Mountlet adds the desktop interface, file browser,
            cache handling, setup helpers, and optional native mounting controls.
          

        

        

          

            
Bundled build

            
Includes an app-local rclone. This is the easiest choice for most people and does not replace a system rclone. On macOS it uses the official rclone binary for folder mounting.

          

          

            
Lean build

            
Uses rclone already installed on the computer. This is lighter for technical users, admins, and managed machines.

          

          

            
Native mounting

            
Install FUSE, WinFsp, or macFUSE to make cloud accounts appear as ordinary folders in your system file manager.

FAQ

          
Search answers before opening support.

        

        
        

          Can Mountlet replace provider desktop apps?
          
For many daily file tasks, yes. Provider apps may still be better for provider-specific sharing, collaboration, or backup features.

        

        

          Do I need FUSE, WinFsp, or macFUSE?
          
Mountlet's integrated file browser works without them. Add the platform filesystem driver when you want Mountlet to mount cloud accounts as ordinary folders too.

        

        

          What is rclone?
          
It is the cloud access engine Mountlet uses behind the scenes. The bundled build includes it for convenience.

        

        

          Is this open source?
          
The source is available for non-commercial use. Commercial use or redistribution requires separate permission.

        

        

          Does Mountlet need to stay online for licensing?
          
No. Paid builds use a 7-day trial and online activation. Lifetime licenses keep working offline. Subscriptions store a signed local license through the current paid period.

        

        

          Why does the installer show a security warning?
          
Current beta builds are not code-signed or Apple-notarized. Only install Mountlet from this site or Mountlet's GitHub release/build artifacts.

          
    
            
  • Windows: if SmartScreen shows Windows protected your PC, choose More info, then Run anyway.
    • 
            
  • macOS: in Finder, Control-click Mountlet, choose Open, then confirm. If macOS still blocks it, use System Settings > Privacy & Security > Open Anyway for Mountlet.
    • 
            
  • Linux: install the `.deb` normally. For an extracted portable build, mark the launcher executable if your file manager refuses to run it.
    • 
          

          
Do not disable SmartScreen, Gatekeeper, or other system protection globally.

        

        

          Where should I get support?
          
Search this FAQ first. For crashes or reproducible bugs, use Mountlet's in-app report option so logs and platform details are included automatically.

        

        

          What should I include in a bug report?
          
Describe what you were doing, which provider was involved, and what you expected to happen. The in-app reporter can include recent Mountlet and rclone logs with your consent.
