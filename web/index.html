Features

Most daily cloud work, without provider hopping.

Keep many accounts close at hand, open files through your normal apps, and decide which files stay available when the network is not.

  • Browse many cloud accounts side by side.
  • Open files in the apps already associated with those file types.
  • Keep selected files and folders available offline.
  • Sync edits back when the cloud copy has not changed.
  • Move config between devices with encrypted bundles.
  • Optionally mount accounts as normal folders for Finder, Explorer, Dolphin, and other file managers.

How it works

A friendly desktop layer over a proven cloud engine.

Mountlet uses rclone under the hood. rclone is the connection layer that knows how to talk to many cloud providers. Mountlet adds the desktop interface, file browser, cache handling, setup helpers, and optional native mounting controls.

Bundled build

Includes an app-local rclone. This is the easiest choice for most people and does not replace a system rclone.

Lean build

Uses rclone already installed on the computer. This is lighter for technical users, admins, and managed machines.

Native mounting

Optional. Install FUSE, WinFsp, or macFUSE only if you want cloud accounts to appear as ordinary folders.

Platforms

Linux

Primary beta platform. Plasma X11 has the fullest tray behavior; GNOME and Wayland have desktop limits.

FAQ

Short answers before you install.

Can Mountlet replace provider desktop apps?

For many daily file tasks, yes. Provider apps may still be better for provider-specific sharing, collaboration, or backup features.

Do I need FUSE, WinFsp, or macFUSE?

Only for native folder mounting. Mountlet's integrated file browser works without filesystem mounting.

What is rclone?

It is the cloud connection engine Mountlet uses behind the scenes. The bundled build includes it for convenience.

Is this open source?

The source is available for non-commercial use. Commercial use or redistribution requires separate permission.
